# Port

Портфолио дизайнера на Nuxt и Vue с TypeScript, по исходному макету Figma.

## Запуск

```sh
npm ci
npm run dev
```

Локальный адрес: http://localhost:3000

## Проверка и сборка

Для локальной разработки и CI используются Node.js 26.12.0 и npm 12.2.0.

```sh
npm run typecheck
npm run generate
python3 -m http.server 3000 --directory .output/public
```

Статический сайт генерируется в `.output/public`.
Код приложения находится в `app/`. Главный компонент — `app/app.vue`.
Версии зависимостей закреплены в `package.json` и `package-lock.json`.

## Публикация через GitHub

Основной адрес: https://adamets.kz. `www.adamets.kz` перенаправляется на основной адрес.

Репозиторий: [Radion13/adamets-portfolio](https://github.com/Radion13/adamets-portfolio).
Проверки и публикации: [GitHub Actions](https://github.com/Radion13/adamets-portfolio/actions/workflows/pages.yml).

Единственный рабочий канал публикации — GitHub Actions и GitHub Pages.
Изменения можно вносить через редактор GitHub или локально с последующим `git push origin main`.
После каждого push в `main` workflow `.github/workflows/pages.yml` устанавливает зависимости
через `npm ci`, проверяет типы, генерирует статику и публикует `.output/public`.
Если проверка или сборка завершается ошибкой, текущая опубликованная версия сохраняется.
Pull request запускает только проверку и сборку. Повторный деплой можно запустить
вручную через **Actions → Build and deploy GitHub Pages → Run workflow**, выбрав `main`.

В **Settings → Pages** источник публикации — **GitHub Actions**, custom domain —
`adamets.kz`, HTTPS включён после выпуска сертификата. Базовый URL приложения — `/`.
Workflow использует встроенный `GITHUB_TOKEN` и OIDC; отдельные токены и SSH-ключи
для публикации в Actions не нужны.

Служебная привязка проекта к ChatGPT Sites удалена. Старая закрытая копия Sites
сохранена как резервная и не участвует в последующих публикациях.

Для отката отмените нужный коммит через `git revert <SHA>` и отправьте результат в `main`.
Откат пройдёт тот же цикл проверки и автоматической публикации.

## Контент и поведение

- Контакты и ссылка на резюме: `app/data/portfolio.ts`. Пока URL равен `null`,
  кнопка показывает сообщение-заглушку. Добавьте адрес, чтобы она стала ссылкой.
- Описание компании: `eurasianBank` в том же файле.
- `CompanyCaseStudy.vue` ограничивает липкую левую колонку карточками своей
  компании. Для следующей компании добавьте ещё один экземпляр с её данными
  и карточками в слоте. Внутренней области прокрутки нет.
- На экранах до 850 px и при высоте окна до 650 px описание не закрепляется,
  чтобы оставаться доступным при чтении.
- Меню закреплено сверху. Приветствие и места работы активируют логотип,
  кейсы — пункт «кейсы», About — «кто я?», блок с коктейлем — «контакты».
- Главный кейс открывает обзор в диалоге; Escape закрывает его и возвращает фокус.
- Учитывается системная настройка уменьшения движения.

Исходные узлы и ограничения экспорта описаны в `design/README.md`.

## Версии и проверка

Nuxt 4.6.2, Vue 3.5.44, TypeScript 6.0.3, vue-tsc 3.3.13.
Версии проверены в npm при настройке проекта.
TypeScript 7 пока несовместим с текущим vue-tsc.

Проверки `npm run typecheck` и `npm run build` прошли успешно.
Локальный сервер отвечает HTTP 200.

На момент установки `npm audit` сообщает о 11 high-записях в дереве
зависимостей, связанных с `braces` и `node-forge`.
Исправленные версии этих двух пакетов в npm пока отсутствуют.
