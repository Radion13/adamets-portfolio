# Port

Портфолио дизайнера на Nuxt и Vue с TypeScript, по исходному макету Figma.

## Запуск

```sh
npm ci
npm run dev
```

Локальный адрес: http://localhost:3000

## Проверка и сборка

```sh
npm run typecheck
npm run build
npm run preview
```

Код приложения находится в `app/`. Главный компонент — `app/app.vue`.
Версии зависимостей закреплены в `package.json` и `package-lock.json`.

## Контент и поведение

- Контакты и ссылка на резюме: `app/data/portfolio.ts`. Пока URL равен `null`,
  кнопка показывает сообщение-заглушку. Добавьте адрес, чтобы она стала ссылкой.
- Описание компании: `eurasianBank` в том же файле.
- `CompanyCaseStudy.vue` ограничивает липкую левую колонку карточками своей
  компании. Для следующей компании добавьте ещё один экземпляр с её данными
  и карточками в слоте. Внутренней области прокрутки нет.
- На экранах до 850 px и при высоте окна до 650 px описание не закрепляется,
  чтобы оставаться доступным при чтении.
- Меню закреплено сверху. Приветствие и места работы активируют логотип,
  кейсы — пункт «кейсы», блок с коктейлем — «контакты».
- Главный кейс открывает обзор в диалоге; Escape закрывает его и возвращает фокус.
- Учитывается системная настройка уменьшения движения.

Исходные узлы и ограничения экспорта описаны в `design/README.md`.

## Версии и проверка

Nuxt 4.6.2, Vue 3.5.44, TypeScript 6.0.3, vue-tsc 3.3.13.
Версии проверены в npm при настройке проекта.
TypeScript 7 пока несовместим с текущим vue-tsc.

Проверки `npm run typecheck` и `npm run build` прошли успешно.
Локальный сервер отвечает HTTP 200.

На момент установки `npm audit` сообщает о 11 high-записях в дереве
зависимостей, связанных с `braces` и `node-forge`.
Исправленные версии этих двух пакетов в npm пока отсутствуют.
