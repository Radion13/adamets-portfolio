# Источник дизайна

- Страница: https://www.figma.com/design/5qmYnrrBBIAUwK5b6Atlno/Портфолио?node-id=859-6558
- Компоненты и состояния: https://www.figma.com/design/5qmYnrrBBIAUwK5b6Atlno/Портфолио?node-id=859-7072
- Обводка активного меню: исходный SVG узла `803:6546`.

Иллюстрации, логотипы, формы карточек, разделители и телефоны экспортированы
из исходного файла. Тексты и доступные контакты остаются редактируемым HTML.
Шрифты Caveat, Advent Pro и Inter сохранены локально; лицензии находятся
в `public/fonts/`.

Основной размер макета — 1512 px. На узких экранах сетка перестраивается.
Карточки используют оригинальные SVG фонов и отдельных рисунков hover-вариантов
из раздела компонентов. Они сохранены в `public/images/cases/` с ID исходных узлов.
Начальные и конечные координаты, размеры и повороты записаны в `app/data/caseArtwork.ts`.
Маленькие карточки переходят за 800 мс (Gentle, в CSS — `--spring`), большая —
за 300 мс с Ease out. Gentle приближён кубической кривой браузера; координаты
и повороты взяты из полей Design. Телефоны при наведении неподвижны.

У каждой карточки фон, заливка и телефон обрезаются одним общим контуром.
Файлы `mini-card-fill.svg` и `featured-card-fill.svg` содержат исходные градиенты
Figma на прямоугольной поверхности; форму задаёт маска карточки. Это исключает
расхождение зеркального hover-контура с обычным контуром и маской телефона.
